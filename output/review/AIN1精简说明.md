# AIN1 精简说明

当前只配置和采样 AIN1，其他通道不再扫描或检查量程。RST 外接线保持不接，使用模块板载上拉；CubeMX 和 SPI 配置无修改。

## 保留

- 10 ms 任务调度、100 ms 采样周期。
- AIN1 的 MAN1（C400h）+ NOOP、每帧 5 字节、通道标签校验。
- AIN1 量程寄存器 06h 写 05h，即 0～10.24 V。
- 原有距离公式、正向/反向两点校准。
- SPI 超时、寄存器/通道校验、初始化重试、失败输出 NAN。
- 单通道快照与过期检测、FreeRTOS 栈/内存故障处理。

## 删除

- 8 路扫描、其他通道量程配置、多通道数组及通道有效掩码。
- TX/RX 调试快照、寄存器观察变量、故障历史和累计错误计数。
- 任务/采样/重初始化计数、耗时与超期统计、栈水位统计、RTOS 故障观察变量。

## 使用

- 距离：`g_distance_mm`，单位 mm。
- AIN1 原始码：`g_ads_ain1_raw`，替代原来的 `g_ads_channel_raw[1]`。
- `g_ads_init_ok` / `g_ads_spi_ok` 保留为运行所需状态。
- 其他任务使用 `Laser_GetSample()`；快照的 `raw` 为单个 AIN1 码值，`valid` 为本次通信及通道校验结果，`status` 保留错误/过期/满量程/校准状态。

旧 Watch 中已删除的变量可以移除。

## 验证

Debug / Release 构建通过；16 项主机回归通过，覆盖 AIN1 唯一通道命令、采样周期、0/5/10 V 换算、校准、配置异常和传输失败恢复。SPI 模式和距离换算函数保持原样。主机模拟不验证实物时序；本次未烧录。

修改前源码备份：`pre-ain1-cleanup-source.zip`。主机验证：`mock/review_harness.c`、`mock/results.txt`，不参与固件构建。
